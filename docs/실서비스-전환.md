# 프로토타입 → 실제 서비스로 바꾸려면

지금 앱은 **서버 없이** 동작해요(주문·가게 정보는 각 기기 안에 저장). 실제로 손님과 사장님이 서로 다른 폰에서 주고받으려면 아래를 붙이면 돼요. 앞쪽일수록 먼저 필요해요.

| 순서 | 무엇을 | 추천 도구 | 왜 |
|---|---|---|---|
| 1 | **데이터 저장(DB) + 로그인** | Supabase(무료로 시작) 또는 Firebase | 주문·가게 정보를 서버에 저장해 다른 폰에서도 보이게. 지금의 `src/lib/state.js` 저장 부분만 바꾸면 돼요 |
| 2 | **사진 저장** | Supabase Storage | 손님 참고 사진·사장님 작품 사진을 서버에 올리기 |
| 3 | **알림** | 카카오 알림톡(Solapi 등 대행) / 웹 푸시 | 새 주문·확정·픽업 안내를 카톡으로 |
| 4 | **예약금 결제** | 토스페이먼츠 | 지금은 ‘입금 확인’ 버튼 → 자동 결제 확인으로 |
| 5 | **카카오 지도·장소 검색** | 카카오 개발자 JavaScript 키 | 지금도 설정에 키를 넣으면 바로 켜져요(전국 가게 검색) |
| 6 | **AI** | Claude API (서버에서 호출) | 지금은 기기에 키를 넣는 방식 → 실서비스는 서버에서 호출해 키를 숨겨요 |
| 7 | **안드로이드·아이폰 앱** | Capacitor (`tools/ci/android.yml` 준비됨) | GitHub 로그인에 workflow 권한을 추가하면 APK가 자동으로 만들어져요 |

## 운영 전에 꼭 챙길 것
- **개인정보 처리방침**: 이름·연락처를 받으므로 수집 목적·보관 기간·파기 방법을 공개해요.
- **입점 가게 확인**: 영업신고된 가게만 입점(식약처 안내: SNS 무신고 판매 주의).
- **저작권 캐릭터**: 앱에서 ‘사장님 확인 필요’로 표시하고, 최종 판단은 가게가 하도록 안내해요.
- **가게 공개 정보**: 지금 들어 있는 43곳은 2026-11 공개 자료 기준이에요. 서비스 전에는 가게에 직접 확인하거나, 사장님이 ‘우리 가게 찾기’로 고치게 해요.

## 수익 구조 아이디어 (팀 회의 내용 정리)
- 처음엔 사장님 **무료 입점**(대학생 프로젝트로 제안) → 앱 주문이 늘면 **주문 수수료** 또는 **월 구독**(참고: 똑톡 월 5,000~45,000원, 부카 월 9,900원~)
- 손님에게는 무료, 선물하기·당일 픽업 같은 편의 기능을 키워요.
