# 프로토타입 → 실제 서비스로 바꾸려면

지금 앱은 **자체 서버 없이** 동작해요.
- 주문·가게 정보·장부는 각자 기기 안에 저장돼요.
- 손님 폰과 사장님 폰 사이의 주문·대화는 기기에서 암호화한 뒤 공개 중계 서비스(ntfy.sh)를 거쳐 전달돼요. 중계 서버는 12시간만 보관해요.

발표와 소규모 시범 운영에는 충분하지만, 정식 서비스에는 아래가 필요해요. 앞쪽일수록 먼저 필요해요.

| 순서 | 무엇을 | 추천 도구 | 왜 |
|---|---|---|---|
| 1 | **데이터 저장(DB) + 로그인** | Supabase(무료로 시작) 또는 Firebase | 폰을 바꾸거나 12시간 넘게 앱을 안 열어도 주문이 남게. `src/lib/live.js`의 전송 부분과 `src/lib/state.js`의 저장 부분만 바꾸면 돼요 |
| 2 | **사진 저장** | Supabase Storage | 참고 사진·시안·작품 사진을 서버에 올리기(지금은 작게 줄여서 암호화 전송) |
| 3 | **앱을 닫아도 오는 알림** | 카카오 알림톡(Solapi 등 대행) / 웹 푸시 | 지금은 앱을 열어 둔 동안만 실시간 알림이 와요 |
| 4 | **예약금 결제** | 토스페이먼츠 | 지금은 ‘입금 확인’ 버튼 → 자동 결제 확인으로 |
| 5 | **구글 지도 키를 기본값으로** | Google Maps Platform | 지금은 키를 넣은 기기에서만 구글 지도. [구글지도-연결.md](구글지도-연결.md) 참고 |
| 6 | **AI** | Claude API (서버에서 호출) | 지금은 기기에 키를 넣는 방식 → 실서비스는 서버에서 호출해 키를 숨겨요 |
| 7 | **안드로이드·아이폰 앱** | Capacitor (`tools/ci/android.yml` 준비됨) | GitHub 로그인에 workflow 권한을 추가하면 APK가 자동으로 만들어져요 |

## 운영 전에 꼭 챙길 것
- **개인정보 처리방침**: 이름·연락처를 받으므로 수집 목적·보관 기간·파기 방법을 공개해요.
- **입점 가게 확인**: 영업신고된 가게만 입점(식약처 안내: SNS 무신고 판매 주의). 지금은 누구나 ‘우리 가게 찾기’로 등록할 수 있어서, 정식 서비스에서는 사업자 확인 절차가 필요해요.
- **저작권 캐릭터**: 앱에서 ‘사장님 확인 필요’로 표시하고, 최종 판단은 가게가 하도록 안내해요.
- **가게 공개 정보**: 지금 들어 있는 47곳은 2026-11 공개 자료 기준이에요. 영업이 확인된 곳은 8곳, 공개 가격이 있는 곳은 16곳이고 나머지는 ‘확인 필요’로 표시돼요. 서비스 전에는 가게에 직접 확인하거나, 사장님이 입점해서 직접 고치게 해요.

## 수익 구조 아이디어 (팀 회의 내용 정리)
- 처음엔 사장님 **무료 입점**(대학생 프로젝트로 제안) → 앱 주문이 늘면 **주문 수수료** 또는 **월 구독**(참고: 똑톡 월 5,000~45,000원, 부카 월 9,900원~)
- 손님에게는 무료, 선물하기·당일 픽업 같은 편의 기능을 키워요.
