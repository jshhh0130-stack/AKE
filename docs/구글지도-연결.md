# 구글 지도 연결하기 (약 5~10분)

구글 지도 키를 앱에 넣으면 지도가 구글 지도로 바뀌고, 가게의 **실제 사진 · 별점 · 영업시간 · 정확한 위치**를 구글에서 받아 와요.
키는 구글 계정 주인만 만들 수 있어서 직접 한 번 해 주셔야 해요.

## 순서
1. https://console.cloud.google.com 에 구글 계정으로 로그인해요.
2. 위쪽 **프로젝트 선택 → 새 프로젝트** (이름 예: dear-cake) → 만들기.
3. 왼쪽 메뉴 **결제 → 결제 계정 연결**. 카드 등록이 필요해요.
   - 구글은 API마다 **매달 무료 사용량**을 줘요(지도 불러오기 1만 번, 장소 정보 1천~5천 번 정도). 수업·발표 수준이면 그 안에서 끝나요.
   - 걱정되면 **결제 › 예산 및 알림**에서 예산 1,000원 알림을 걸어 두세요.
4. 왼쪽 메뉴 **API 및 서비스 → 라이브러리**에서 아래 두 개를 찾아 **사용**을 눌러요.
   - **Maps JavaScript API**
   - **Places API (New)**
5. **API 및 서비스 → 사용자 인증 정보 → 사용자 인증 정보 만들기 → API 키**. `AIza…` 로 시작하는 키가 나와요.
6. 만든 키를 눌러 **제한**을 걸어요 (다른 사람이 내 키를 못 쓰게).
   - 애플리케이션 제한사항: **웹사이트**
   - 웹사이트 추가: `https://jshhh0130-stack.github.io/*`
   - API 제한사항: Maps JavaScript API, Places API (New) 두 개만 선택
7. 앱에서 **마이 › 지도 · AI 연결 › 구글 지도 연결**에 키를 붙여 넣고 **저장하고 확인**.

## 모든 사람에게 구글 지도로 보이게 하려면
위 방법은 키를 넣은 그 폰에서만 구글 지도가 돼요. 누구에게나 구글 지도로 보이게 하려면 키를 앱에 기본값으로 넣어야 해요.
키를 알려 주시면 넣어 드릴게요. (6번의 웹사이트 제한을 걸어 둔 키는 공개 코드에 넣어도 다른 사이트에서는 못 써요.)

## 잘 안 될 때
- “연결 실패”가 뜨면: 4번의 두 API를 **사용 설정**했는지, 3번 **결제 계정**이 연결됐는지, 6번 웹사이트 주소가 맞는지 확인해요.
- 키를 만든 직후에는 5분쯤 걸릴 수 있어요.
- 앱은 키가 틀리면 자동으로 기본 지도로 돌아가요.

## 구글에서 받아 오는 것과 아닌 것
| 구글에서 받아 옴 | 앱이 따로 가진 정보 |
|---|---|
| 지도, 가게 실제 사진, 별점·리뷰 수, 영업시간, 정확한 위치, 폐업 표시 | 커스텀 케이크 종류, 크기별 가격, 주문 마감, 인스타·카톡 채널 |

구글 리뷰 글 자체와 네이버·카카오 후기는 가져오지 않아요(약관 문제). 가게 가격은 사장님이 입점해서 가격표를 넣으면 가장 정확해요.
