# Dear Cake 발표 시연 가이드 (약 5분)

앱 주소: https://jshhh0130-stack.github.io/dear-cake/

## 가장 좋은 시연: 폰 두 대 (또는 노트북 + 폰)
한 대는 **사장님**, 한 대는 **손님**이 되면 주문과 대화가 실제로 오가는 걸 보여 줄 수 있어요.

**준비 (발표 전)**
1. 사장님 기기: 앱 열기 → **사장님용** → “우리 가게 찾기”에서 가게 하나 고르기(예: 미도리케이크) → 다음·다음·다음 → **등록 완료**
2. 사장님 기기: **내 가게 › 주문 링크·QR** 화면을 띄워 두기 (초록색 “실시간 연결됨” 확인)

**시연 순서**
| 순서 | 누가 | 할 일 | 말할 내용(예시) |
|---|---|---|---|
| 1 | 손님 | 앱 → 고객용 → 찾기 막대에 “인계동 4만원대 캐릭터 케이크” | “말 한마디나 사진 한 장으로 맞는 가게를 찾아요.” |
| 2 | 손님 | 사장님 기기의 **QR을 카메라로 찍기** → 가게 주문 페이지 | “인스타 프로필의 링크·QR이 곧 주문창이에요.” |
| 3 | 손님 | 주문서 → 한 줄로 채우기(“토요일 3시 1호 핑크 하트, 문구 ‘생일 축하해’”) → 문구 확인 → **사장님께 보내기** | “고를 때마다 시안과 가격이 바뀌고, 오타는 한 글자씩 확인해요.” |
| 4 | 사장님 | 알림과 함께 주문 도착 → (규칙 안이면 자동 확정) → **앱 시안으로 확인받기** + 메시지 | “사장님은 승인만. 규칙 안 주문은 자동 확정돼요.” |
| 5 | 손님 | 대화방에 시안 도착 → **수정 요청**(문구 수정) 또는 **이대로 만들어 주세요** | “제작 전에 시안을 보고 바로 고칠 수 있어요.” |
| 6 | 사장님 | 매출·장부: 오늘/이번 주/이번 달 그래프, 월별 장부, 근무기록 | “주문이 곧 장부가 돼요.” |

> 사장님 매출 화면을 풍성하게 보여 주려면 **내 가게 › 예시 주문 넣어 보기**를 누르세요(나중에 지울 수 있어요).

## 폰이 한 대뿐이면
손님으로 주문 → 완료 화면의 **(체험) 이 가게 사장님 화면에서 받아 보기** → 승인·시안·메시지 → 마이에서 고객 모드로 돌아와 대화방 확인.

## 예상 질문
- **가게가 진짜인가요?** 수원에 실제로 있는 커스텀 케이크 전문점 47곳이에요. 영업 확인된 곳과 확인이 필요한 곳을 구분해 표시해요.
- **가격이 정확한가요?** 입점 가게는 사장님 가격표 그대로, 그 외는 공개 가격·수원 평균으로 만든 ‘추정 범위’라고 표시해요.
- **실제로 주문이 가나요?** 입점 가게는 주문·대화가 암호화돼 사장님 폰으로 실시간 전달돼요. 입점 전 가게는 완성된 주문서를 카톡·인스타로 보내요.
- **AI는 어디에?** 말로 찾기, 사진 분석, 한 줄 주문 채우기, 가격표 사진 읽기, 가게에 물어보기. 키가 없으면 규칙 기반으로, Claude API 키를 넣으면 진짜 AI로 동작해요.
- **구글 지도인가요?** Google Maps API 키를 넣으면 구글 지도 + 구글의 실제 사진·별점이 나와요. 키가 없으면 무료 지도로 같은 화면이에요.
- **똑톡과 다른 점?** 손님이 지도·사진·말로 가게를 찾고 가격·시안을 보고 고르는 화면 + 사장님과의 대화방·시안 확인까지 한 앱에서 끝나요.
