# 에이크 발표 시연 가이드 (약 5분)

앱 주소: https://jshhh0130-stack.github.io/AKE/

## 가장 좋은 시연: 폰 두 대 (또는 노트북 + 폰)
한 대는 **사장님**, 한 대는 **손님**이 되면 주문과 대화가 실제로 오가는 걸 보여 줄 수 있어요.

**준비 (발표 전)**
1. 사장님 기기: 앱 열기 → **사장님용** → “우리 가게 찾기”에서 가게 하나 고르기(예: 미도리케이크) → 다음·다음·다음 → **등록 완료**
2. 사장님 기기: **내 가게 › 주문 링크·QR** 화면을 띄워 두기 (초록색 “실시간 연결됨” 확인)
3. 손님 기기: 처음부터 보여 주려면 **마이 › 사용법 다시 보기** (또는 컴퓨터 화면 옆 “처음부터”)

**시연 순서**
| 순서 | 누가 | 할 일 | 말할 내용(예시) |
|---|---|---|---|
| 1 | 손님 | 앱 → **고객용** → 지도가 바로 열리고 안내 5단계 | “누구나 바로 쓸 수 있게, 첫 화면에서 칸을 하나씩 짚어 줘요.” |
| 2 | 손님 | 검색창에 **제델** → ‘제이델링’ / **AI로 케이크 가게 찾기**에 “영통 4만원대 캐릭터” | “가게 이름을 줄여 써도, 말로 써도 찾아요.” |
| 2-1 | 손님 | AI로 케이크 가게 찾기 → **사진 넣기**(또는 예시) → **AI 실사 사진 만들기** → **그림판으로 고치기**(문구 얹기) → **이 사진으로 가게 찾기** | “원하는 사진을 넣으면 AI가 실사 케이크로 바꾸고, 그림판으로 고친 그대로 가게를 찾아요.” |
| 3 | 손님 | 핀 누르기 → 가게 카드 옆으로 넘기기 → **위치 공유** | “캐치테이블처럼 지도에서 바로 비교하고, 위치를 친구에게 보내요.” |
| 4 | 손님 | **관심** → 케이크 사진 둘러보기 → 하트 → 사진 누르기 → **이 케이크 만드는 가게 찾기** | “핀터레스트처럼 고르면, 그걸 만드는 가까운 가게까지 바로 이어져요.” |
| 5 | 손님 | 사장님 기기의 **QR을 카메라로 찍기** → 주문서 → 한 줄로 채우기 → **사장님께 보내기** | “고를 때마다 시안과 가격이 바뀌고, 오타는 한 글자씩 확인해요.” |
| 6 | 사장님 | 알림과 함께 주문 도착 → 승인 → **앱 시안으로 확인받기** + 메시지 | “사장님은 승인만. 규칙 안 주문은 자동 확정돼요.” |
| 7 | 사장님 | 매출·장부: 그래프, 월별 장부, 근무기록 | “주문이 곧 장부가 돼요.” |

> 사장님 매출 화면을 풍성하게 보여 주려면 **내 가게 › 예시 주문 넣어 보기**를 누르세요(나중에 지울 수 있어요).

## 폰이 한 대뿐이면
손님으로 주문 → 완료 화면의 **(체험) 이 가게 사장님 화면에서 받아 보기** → 승인·시안·메시지 → 마이에서 고객 모드로 돌아와 대화방 확인.

## 예상 질문
- **가게가 진짜인가요?** 수원에 실제로 있는 커스텀 케이크 전문점 47곳이에요. 영업 확인된 곳과 확인이 필요한 곳을 구분해 표시해요.
- **관심 탭 사진은 진짜 가게 사진인가요?** 아니요. 공개 AI 모델(FLUX.1 schnell, 자유 이용 라이선스)로 만든 **예시 사진**이고 화면에 ‘예시’로 표시해요. 다른 사람 사진은 링크로만 열어요. 입점 가게가 작품을 올리면 ‘가게 작품’으로 함께 보여요.
- **AI 실사 사진은 바로 나오나요?** 무료 AI는 인터넷 주소마다 하루 몇 번이라, 발표 전에 같은 와이파이에서 여러 번 해 보면 다 써 버릴 수 있어요. 그때는 무료 대기열(10~20분)로 넘어가요. 발표 때는 **휴대폰 데이터**로 하거나, 설정에 **허깅페이스 무료 토큰**(또는 제미나이 키)을 넣어 두면 안전해요. 기다리는 동안 ‘비슷한 예시 사진’을 눌러 그림판 시연을 이어 가면 돼요.
- **가격이 정확한가요?** 입점 가게는 사장님 가격표 그대로, 그 외는 공개 가격·수원 평균으로 만든 ‘추정 범위’라고 표시해요.
- **실제로 주문이 가나요?** 입점 가게는 주문·대화가 암호화돼 사장님 폰으로 실시간 전달돼요. 입점 전 가게는 완성된 주문서를 카톡·인스타로 보내요.
- **구글 지도인가요?** Google Maps API 키를 넣으면 구글 지도 + 실제 사진·별점이 나와요. 키가 없으면 무료 지도로 같은 화면이에요.
- **왜 이름이 에이크인가요?** C를 비워 둔 CAKE예요. 손님이 원하는 걸 채우는 순간 케이크가 된다는 뜻이에요.
