# Dear Cake 발표 시연 가이드 (약 4분)

앱 주소: https://jshhh0130-stack.github.io/dear-cake/
컴퓨터로 열면 오른쪽에 핸드폰 화면, 왼쪽에 **QR 코드**와 **🎬 발표 시연 순서** 버튼이 있어요. 심사위원이 QR로 직접 열어 보게 해도 좋아요.

> 시작 전: 왼쪽 패널 › 발표 시연 순서 › **처음부터**를 눌러 깨끗한 상태로 만들어 두세요.

| 순서 | 화면에서 할 일 | 말할 내용(예시) |
|---|---|---|
| 1. 문제 (20초) | 📊 시장 데이터 › “주문 과정 7단계 → 3단계” | “지금은 인스타 캡처→카톡 상담→주문서 복붙→가격 안내→입금→확인 톡까지 7단계예요. 가격은 4단계에서야 알아요.” |
| 2. 찾기 (40초) | 고객용 → 가이드 넘기기 → 지도 → **사진으로 찾기 › 예시(곰돌이 그림)** | “원하는 케이크 사진 한 장이면, 비슷한 걸 만드는 주변 가게를 일치율 순으로 보여 줘요.” |
| 3. 비교 (20초) | 목록 › **비교** → 2~3곳 선택 → 나란히 비교 | “가게마다 1호가 3.5만~6만 원으로 차이가 커요. 가격·픽업일을 나란히 봐요.” |
| 4. 주문 (60초) | 체험 공방 → 주문서 → **한 줄로 채우기**(“토요일 3시 1호 핑크 하트, 문구 ‘생일 축하해’ 체리”) → 시안 3가지 | “고를 때마다 시안과 가격이 바로 바뀌어요. 가격 먼저, 본 그대로.” |
| 5. 실수 방지 (20초) | 문구 확인하고 주문 요청 → **한 글자씩 확인** · 가게 규칙 확인 | “오타는 한 글자씩 보여 주고, 가게 규칙 안이면 사장님은 승인만 하면 돼요.” |
| 6. 사장님 (60초) | 사장님께 보내기 → **(체험) 사장님 화면에서 받아 보기** → 승인 → 입금 확인 → 정산 | “규칙 안 주문은 자동 확정, 나머지는 ‘승인/수정 요청’ 두 버튼. 응대 지표로 상담 시간이 얼마나 줄었는지 보여 줘요.” |
| 7. 마무리 (20초) | 🎁 선물 카드 또는 사장님 ‘우리 가게 찾기’ | “수원 43곳 공개 정보를 미리 넣어 두어, 사장님은 3분이면 입점해요.” |

## 예상 질문 대비
- **가격이 정확한가요?** 사장님이 가격표를 등록한 가게는 정확, 아닌 가게는 공개 가격·수원 평균으로 만든 ‘추정 범위’라고 표시해요.
- **AI는 어디에?** 사진 분석·한 줄 주문 채우기·가격표 사진 읽기·소개글·가게에 물어보기. 키가 없으면 기기 안 규칙 기반으로 동작하고, Claude API 키를 넣으면 진짜 AI가 동작해요(마이 › AI·지도 연결).
- **실제 주문이 가게에 가나요?** 지금은 서버 없는 프로토타입이라 같은 기기 시연 + 주문서 링크로 전달해요. 실서비스 전환 방법은 `docs/실서비스-전환.md`.
- **똑톡과 다른 점?** 똑톡은 사장님용 주문서 도구, Dear Cake는 손님이 지도·사진으로 찾고 가격·시안을 보고 고르는 화면 + 사장님은 승인만.
