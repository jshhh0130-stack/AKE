# 🎂 Dear Cake · 디어 케이크

**보고 고르고, 본 그대로 받는 커스텀 케이크.**
손님과 케이크 가게 사장님이 한 앱에서 주문을 끝내는 모바일 앱 프로토타입이에요.

| 바로 열기 | 주소 |
|---|---|
| 📱 앱 (핸드폰·컴퓨터) | **https://jshhh0130-stack.github.io/dear-cake/** |
| 🤖 안드로이드 설치 파일 | [dear-cake.apk 내려받기](https://github.com/jshhh0130-stack/dear-cake/releases/download/app-latest/dear-cake.apk) |

- **아이폰**: 사파리로 앱 주소를 열고 → 공유 버튼 → **홈 화면에 추가** → 앱처럼 실행돼요.
- **안드로이드**: 크롬으로 열고 → 메뉴 → **앱 설치(홈 화면에 추가)**, 또는 위 APK를 설치해요.
- 컴퓨터로 열면 가운데 핸드폰 화면과 함께 **QR 코드**가 보여요. 핸드폰 카메라로 찍으면 바로 열려요.
- 코드를 고쳐서 GitHub에 올리면 **자동으로 다시 배포**돼요 (설치한 앱에도 자동 반영).

## 무엇을 할 수 있나요?

### 고객용
1. **처음 화면** — 핑크 스플래시 → 사장님용 / 고객용 선택 → 1~5단계 사용 가이드(넘겨 보기)
2. **지도 홈** — 내 위치(GPS·동네 검색·자주 찾는 곳) 기준으로 주변 커스텀·레터링 케이크 가게 표시, 반경 1~20km
3. **사진으로 찾기** — 원하는 케이크 사진을 올리면 색·스타일을 분석해 비슷한 케이크를 만드는 가게를 **일치율(%)** 순으로 추천
4. **가게 상세** — 예상 가격표(크기별), 주문 마감·휴무, 예시 디자인, 안내사항, 위치·길찾기(카카오맵·네이버지도), 후기, 정보 출처
5. **한 페이지 주문서** — 고를 때마다 **케이크 시안**과 **예상 가격**이 바로 바뀜
   - 한 줄로 채우기: “토요일 3시 1호 핑크 하트, 문구 ‘생일 축하해’” → 자동 입력
   - 크기 비교(지름·인원·휴대폰 크기), 휴무·마감·꽉 찬 날은 회색
   - 문구 **한 글자씩 확인**(오타 방지), 글씨체 6종·글씨 색
   - **시안 3가지** 비교, **AI 실사 이미지**(베타)
   - **가게 규칙 자동 확인** → “규칙 안 — 사장님은 승인만” / “확인 필요 n개”
6. **주문 후** — 규칙 안 주문은 **자동 확정**, 상태 타임라인, 수정 제안 수락, 제작 전 시안 승인, 후기
7. **입점 전 가게**도 주문서를 완성해 **카톡·인스타로 그대로 보낼 수 있게** 정리 + 주문서 링크

### 사장님용 (똑톡보다 단순하게)
1. **3분 등록** — “우리 가게 찾기”로 공개 정보(주소·가격·휴무)를 미리 채움 → 4단계(기본 정보 → 가격표 → 운영·마감 → 꾸미기)
2. **가격표 한 번만** — 크기별 기본가·모양·디자인·맛·크림·토핑 추가금 → 모든 주문에 자동 적용 (평균가 채우기, **가격표 사진 AI 읽기**)
3. **오늘 화면** — 새 요청, 오늘 픽업, 이번 주 일정, 가게 준비도(%)
4. **주문 처리 두 버튼** — 승인 / 수정 요청 (+ 거절), 최종 금액 조정, 답장 템플릿, 시안 사진 보내기, 제작→픽업 단계 한 번에
5. **주문 달력** — 날짜별 주문 수, 휴무 표시, 하루 최대 주문 수
6. **정산** — 일별·주별·월별 매출, 건수, 평균 단가, 월 목표와 남은 하루 목표, 인기 옵션
7. **가게 꾸미기** — 대표 색·배경 무늬·대표 케이크·소개글(AI), 안내사항·FAQ, 작품 사진, 주문서 항목 켜고 끄기, 주문 링크·QR

## 데이터와 가격 추정
- 수원시 커스텀·레터링 케이크 가게 **43곳** (2026-11 공개 자료 조사: 다이닝코드, 당근 비즈프로필, 지역 목록 사이트, 가게 SNS, 팀 직접 조사)
  - 가격·운영 정보까지 확인된 가게와 이름·주소만 확인된 가게를 구분해 표시해요. 전화번호는 넣지 않았어요.
  - 위치는 주소를 OpenStreetMap으로 좌표로 바꾼 값이에요(일부는 “위치 대략”).
- 다른 지역: “이 근처 케이크 가게 더 찾기” → 공개 지도 데이터(OpenStreetMap) 또는 카카오 장소 검색(키 설정 시)
- 예상 가격
  - 사장님이 등록한 가게: **가격표 그대로(정확)**
  - 공개 가격이 있는 가게: **공개 기본가 + 지역 평균 추가금**
  - 정보가 없는 가게: **수원 평균 범위** (도시락 1.8~2.5만 · 미니 2.6~3.6만 · 1호 3.8~5만 · 2호 5~6.5만 · 3호 6.2~8.5만원)
- 원본 자료: [`tools/stores.source.json`](tools/stores.source.json) (출처 링크 포함)

## AI·지도 연결 (선택)
앱의 **마이 › AI · 지도 연결**에서 설정해요. 키는 그 기기에만 저장되고 GitHub에 올라가지 않아요.
- **Claude API 키**: 사진 분석(문구·장식까지), 한 줄 주문 채우기, 가격표 사진 읽기, 소개글 쓰기. 키가 없으면 기기 안 기본 분석으로 동작.
- **카카오 JavaScript 키**: 카카오 지도 + 카카오 장소 검색(전국). [카카오 개발자](https://developers.kakao.com) → 내 애플리케이션 → 앱 키(JavaScript 키) → 플랫폼 › Web 사이트 도메인에 `https://jshhh0130-stack.github.io` 등록.

## 지금의 한계 (프로토타입)
- 서버가 없어서 주문·가게 정보는 **각 기기 안에** 저장돼요. 같은 폰에서 손님 → 사장님 모드를 바꿔 가며 시연할 수 있고, 다른 폰으로는 **주문서 링크**로 전달해요. 실제 서비스는 로그인·DB(예: Supabase, Firebase)를 붙이면 돼요.
- 결제·알림(문자·카톡)은 아직 없어요.
- 공개 정보는 바뀌었을 수 있어요. 가게가 “우리 가게 찾기”로 직접 고치면 정확해져요.

## 개발 메모
```bash
npm install
npm run dev        # 개발 서버
npm run build      # dist/ 에 결과물
node tools/geocode.mjs     # 가게 주소 → 좌표 (stores.source.json → src/data/stores.json)
node tools/walk.mjs http://localhost:4173/   # 화면 자동 점검(스크린샷)
```
- React 19 + Vite, 지도 Leaflet(OpenStreetMap), 케이크 시안은 직접 만든 SVG 그리기 엔진(`src/lib/cake.js`)
- 안드로이드 APK: Capacitor로 GitHub Actions에서 자동 빌드 (`.github/workflows/android.yml`)
