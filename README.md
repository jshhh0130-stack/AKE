**당신이 채우는 순간, CAKE가 됩니다.**
손님과 케이크 가게 사장님이 한 앱에서 찾기 → 주문 → 대화 → 확정까지 끝내는 커스텀·레터링 케이크 앱이에요.

### 앱 바로 열기 → **https://jshhh0130-stack.github.io/AKE/**

- **아이폰**: 사파리로 위 주소 열기 → 공유 버튼(□↑) → **홈 화면에 추가**
- **안드로이드**: 크롬으로 열기 → **홈 화면에 설치** 버튼(또는 ⋮ 메뉴 → 앱 설치)
- **컴퓨터**: 가운데 핸드폰 화면 + 옆에 **QR 코드**와 **발표 시연 순서**가 보여요.

## 무엇을 할 수 있나요?

### 고객
1. **지도** — 수원 커스텀 케이크 가게가 지도에 모여 있어요. 핀에는 1호 가격, **동그라미 = 케이크 가게 · 도장 = iAKE 입점(앱으로 바로 주문)**.
   - 아래 가게 목록은 **사진 3칸 / 목록** 중 골라 봐요. 정렬: 추천순 · 인기순 · 거리순 · 최신순 · 가격 낮은순
   - 위치 칩을 누르면 내 위치나 동네로 주변 가게를 다시 찾아요
2. **튜토리얼** — 앱을 열 때마다 지도에서 4단계(지도 → 가게 정보 → 내 위치 → AI 찾기). ‘AI 찾기’를 처음 누르면 5단계(AI로 만들기 → 사진 넣고 완성 → 가게 찾기 → 주문서 → 주문 완료). 움직임 없이 바로 넘어가고, 언제든 건너뛸 수 있어요.
3. **AI 찾기** — 말로 찾기 · 사진으로 찾기 · **AI로 원하는 케이크 이미지 만들기**(10가지 카테고리, 레터링 · 판 문구까지 한 번에 들어간 실사 사진)
4. **가게 화면** — 가격(예상가) · 거리 · 키워드 · 영업시간(휴무 포함) · 주소를 한눈에, 바로 아래 케이크 사진. 내려도 뒤로가기 버튼이 위에 남아요.
5. **iAKE AI에게 물어보기** — 가게 정보로 바로 답하고 끝에 ‘(AI가 답변했어요)’. 답할 수 없는 질문은 **사장님 문의로 자동 전달**되고, 답장은 주문·대화 탭에서 봐요.
6. **주문서** — 금액은 모두 **예상가**예요(최종 금액은 사장님이 정해요). 문구를 한 글자씩 확인하면 사장님 주문서에 **‘손님 확인’ 도장**이 찍혀요. 성수기 날짜는 ‘성수기’ 표시(예약금 100% · 변경 불가).
7. **주문 대화방** — 주문이 확정되면 **사장님과 톡방**으로 바로. 사장님 수정 제안 받기, 시안 확인, 주문 고치기(바뀐 내용은 변경 기록으로 남아요), 체험용 결제
8. **알림** — 주문 확정 · 시안 · 메시지 · **픽업 준비 완료**, 그리고 **픽업 하루 전 · 3시간 전** 알림(이 폰에서, 앱을 열어 두거나 다음에 열 때)
9. **관심** — **가게 사진**(수원 가게들의 실제 케이크 사진을 가게별로, 가까운 가게부터 · 크게 보기 · 이 케이크로 주문서 쓰기), AI 예시 케이크 둘러보기, 찜한 가게

### 사장님
1. **가게 등록** — “우리 가게 찾기”로 공개 정보를 미리 채우고 3단계(기본 정보 → 가격표 → 운영·마감)로 끝
2. **오늘** — **카톡 주문 붙여넣기**(카톡 주문 글 → 이름 · 날짜 · 시간 · 사이즈 · 맛 · 크림 색 · 문구 · 판 문구 · 초 · 알레르기 칸으로 나눠 주고, 못 찾은 칸은 ‘확인 필요’), 새 요청 · 손님 문의 · 오늘/내일 픽업(‘안내’로 픽업 전 안내 복사)
3. **새 요청** — 종이 주문서 한 장 + **거절 · 수정 · 주문 받기** 세 버튼. ‘수정’은 금액 · 문구 · 판 문구 · 날짜 · 크기를 고쳐서 손님에게 제안 → 손님이 받으면 그대로 확정
4. **주문 화면** — 위에 5단계(누르면 그 단계 기록), 가운데 종이 주문서(**크게 보기**: 모든 칸 · 문구 한 글자씩 · 금액 내역), 시안 보내기, 입금 확인, 제작 → 픽업. 수정 제안은 대화방에 카드로 가고, 손님은 **자세히 보기**로 바뀐 주문서를 보고 바로 확정해요
5. **운영 규칙** — 휴무 · 주문 마감 · 하루 주문 수 · 예약금, **성수기 날짜**(예약금 100% · 변경 불가 · 하루 주문 수 따로), 자동 확정은 **선택**(기본 꺼짐)
6. **매출 · 월별 장부 · 근무기록** — 그래프, 정산 예정, 달력 장부, 엑셀 저장, 시급 · 월 급여 계산

## 디자인
- 고객은 분홍(#FCECEE), 사장님은 초록(#EFF3E6), 글꼴 SUIT, 연한 체크무늬와 손그림 일러스트. 가게 화면의 칸은 파스텔 노랑 하나로 맞췄어요.
- 로고: 팀이 만든 **초 + AKE** 로고로 아이콘 · 파비콘 · 공유 이미지를 만들어요 → `node tools/make-icons.mjs`

## AI 케이크 이미지는 어떻게 만들어지나요
- **구글 제미나이(나노바나나 Pro)만** 써요(11/24부터). 무료 AI · 대기열은 없앴어요.
- 마이 › 지도 · AI 연결 › **구글 제미나이 키**를 넣어야 만들어져요(이 기기에만 저장, 1장 약 90~180원).
- 레터링 · 판 문구를 프롬프트 첫 문장에 넣고 스타일 참고 사진과 함께 보내서, **글귀까지 한 번에** 들어간 실사 사진이 나와요. 그림판에서 더 고칠 수 있어요.

## 구글 지도 연결
앱 **마이 › 지도 · AI 연결**에 Google Maps API 키를 넣으면 지도가 구글 지도로 바뀌고, 가게의 **실제 사진 · 별점 · 영업시간**을 구글에서 받아 와요.
키가 없으면 무료 지도(OpenStreetMap, 색을 차분하게 눌러 씀)로 똑같이 동작해요. → [docs/구글지도-연결.md](docs/구글지도-연결.md)

## 주문·대화가 전달되는 방식
- 입점 가게로 보낸 주문과 대화는 **기기에서 암호화**(AES-GCM / ECDH)한 뒤 공개 중계 서비스(ntfy.sh)를 거쳐 상대 폰으로 가요. 중계 서버는 내용을 읽을 수 없고 12시간만 보관해요.
- 주문 기록은 각자 기기에 저장돼요. 정식 서비스로 가려면 → [docs/실서비스-전환.md](docs/실서비스-전환.md)

## 개발 메모
```bash
npm install
npm run dev                       # 개발 서버
node tools/deploy.mjs             # 빌드 → gh-pages 배포 + main 올리기
node tools/make-icons.mjs         # 로고 → 앱 아이콘·파비콘·공유 이미지
node tools/gallery/build.mjs      # 관심 탭 사진 줄이기 + 한글 문구 얹기 → public/gallery, src/data/gallery.json
node tools/walk.mjs               # 화면 자동 점검 (한 기기)
node tools/walk-live.mjs          # 폰 두 대 실시간 주문·대화 점검
node tools/walk-ai.mjs [--wait]   # AI 실사 사진 · 그림판 점검 (--wait: 무료 대기열 사진 완성까지)
node tools/look.mjs               # 디자인 확인용 스크린샷
powershell -File tools/shop-photos.ps1 -Src "<수원가게사진\가게사진 경로>" -OutDir public/shops -Json src/data/shopPhotos.json   # 가게 사진 줄이기 + 목록
```
- AI 실사 사진: `src/lib/imagegen.js`(엔진 순서), `src/components/AIStudio.jsx`(사진 창), `src/components/Sketch.jsx`(그림판)
- React 19 + Vite, 지도: Google Maps / Kakao / Leaflet(OpenStreetMap), 케이크 시안: 자체 SVG 엔진(`src/lib/cake.js`)
- 첫 화면 안내: `src/components/Coach.jsx`, 위치 공유: `src/components/Share.jsx`, 관심: `src/screens/customer/Interest.jsx`
- 저장 키(`dearcake:v2`)는 그대로예요. 바꾸면 이미 쓰던 사람의 주문·찜이 사라져요.
