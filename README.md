## 무엇을 할 수 있나요?

### 고객
1. **찾기** — 첫 화면의 큰 찾기 막대 하나로
   - **말로**: “영통 근처 4만원대 캐릭터 케이크” → 종류·예산·지역을 알아서 해석
   - **사진으로**: 원하는 케이크 사진을 올리면 색·스타일을 분석
   - **조건으로**: 종류 · 예산(1호 기준) · 지역(4개 구) · 당일 가능 · 앱 주문 가능
   - 조건에 딱 맞는 가게와 조금 다른 가게를 나눠서, **일치율(%)** 과 함께 보여 줘요
2. **지도** — 수원시의 **실제 커스텀 케이크 전문점 47곳**. 핀에 대표 색(또는 실제 사진)과 **가격**이 바로 보여요
   (분홍 = 앱 주문 가능, 테두리만 = 가격 공개, 회색 = 확인 필요)
3. **가게 상세** — 예상 가격표, 주문 마감·휴무, 영업 확인 여부, 가게에 물어보기, 길찾기, 정보 출처
4. **한 페이지 주문서** — 고를 때마다 케이크 시안과 가격이 바뀌고, 문구를 한 글자씩 확인해요
5. **주문 대화방** — 주문마다 사장님과 1:1 대화방
   - 사장님 승인 / 수정 제안 → **이대로 확정** 또는 **다르게 요청**
   - **제작 전 시안** 도착 → **이대로 만들어 주세요** 또는 **수정 요청**(문구·색·위치…)
   - **주문 내용 고치기**(문구·색·픽업 시간): 제작 시작 전까지. 가게 규칙 안이면 다시 자동 확정
   - 사진·메시지 주고받기, 입금 확인, 픽업 준비 알림
6. **알림** — 주문 상태 · 시안 도착 · 메시지 알림을 각각 켜고 끌 수 있어요(소리·진동·휴대폰 알림창)
7. 가게 비교, 찜, 선물하기(선물 카드 링크), 다시 주문, 후기

### 사장님
1. **3분 등록** — “우리 가게 찾기”로 공개 정보를 미리 채우고 4단계로 끝
2. **주문 링크·QR** — 인스타 프로필·계산대에 걸어 두면 **손님 폰의 주문이 사장님 폰에 실시간으로** 도착
3. **오늘** — ① 확인할 주문 ② 새 소식 ③ 오늘 픽업, 순서대로만 보면 돼요
4. **주문 대화방** — 승인 / 수정 제안 두 버튼, 시안 사진 보내기, 입금 확인, 제작 → 픽업 단계
   (가격표 안의 주문은 **자동 확정**)
5. **매출** — 오늘 / 이번 주 / 이번 달, 지난 기간 대비 ▲▼, 막대 그래프(누르면 그날 금액), 정산 예정·입금 전, 월 목표
6. **월별 장부** — 달력 칸마다 그날 주문 수·매출, 날짜를 누르면 주문 하나하나(금액·입금), 주차별 합계, 엑셀 저장
7. **근무기록** — 출근·퇴근·휴게 시간, 직원 시급 → 한 달 근무 시간·급여 자동 계산, 그날 만든 케이크 수
8. 가격표(한 번만), 운영·마감, 가게 꾸미기, 작품 사진, 알림 설정

## 구글 지도 연결
앱 **마이 › 지도 · AI 연결**에 Google Maps API 키를 넣으면
- 지도가 **구글 지도**로 바뀌고
- 가게의 **실제 사진 · 별점 · 영업시간 · 정확한 위치**를 구글에서 받아 와요 (가게를 열어 볼 때만 불러와 사용량을 아껴요)
- 전국 케이크 가게 검색도 구글로 해요

키가 없으면 무료 지도(OpenStreetMap)로 똑같이 동작해요. 키 받는 방법: [docs/구글지도-연결.md](docs/구글지도-연결.md)

## 데이터
- 수원시 커스텀 케이크 전문점 **47곳** (2026-11-17 재조사). 만든(가상) 가게는 없어요.
  - 2025~2026 영업 흔적 확인 8곳 · 공개 가격 확인 16곳 · 나머지는 이름·주소만 확인(‘확인 필요’ 표시)
  - 일반 빵집·프랜차이즈·폐업 의심 가게는 제외, 전화번호는 넣지 않음
  - 원본: [`tools/stores.source.json`](tools/stores.source.json) (출처 링크 포함), 조사 기록: `tools/research/`
- 예상 가격: 입점 가게는 **가격표 그대로**, 공개 가격이 있으면 **공개 기본가 + 평균 추가금**, 없으면 **수원 평균 범위**

## 주문·대화가 전달되는 방식
- 입점 가게로 보낸 주문과 대화는 **기기에서 암호화**(AES-GCM / ECDH)한 뒤 공개 중계 서비스(ntfy.sh)를 거쳐 상대 폰으로 가요. 중계 서버는 내용을 읽을 수 없고 12시간만 보관해요.
- 앱을 열어 둔 동안 실시간으로 받고, 닫아 둔 동안 온 것은 다시 열 때(12시간 안) 받아요.
- 주문 기록은 각자 기기에 저장돼요. 정식 서비스로 가려면 → [docs/실서비스-전환.md](docs/실서비스-전환.md)

## 개발 메모
```bash
npm install
npm run dev                  # 개발 서버
node tools/deploy.mjs        # 빌드 → gh-pages 배포 + main 올리기
node tools/build-stores.mjs  # 조사 결과 합치기 → node tools/geocode.mjs (주소 → 좌표)
node tools/walk.mjs          # 화면 자동 점검 (한 기기)
node tools/walk-live.mjs     # 폰 두 대 실시간 주문·대화 점검
```
- React 19 + Vite, 지도: Google Maps / Kakao / Leaflet(OpenStreetMap), 케이크 시안: 자체 SVG 엔진(`src/lib/cake.js`)
- 주문은 이벤트 기록(`src/lib/orders.js`), 암호화 전송(`src/lib/sync.js`, `src/lib/live.js`)
- 자동 배포·안드로이드 APK 워크플로는 `tools/ci/`에 준비돼 있어요(GitHub 로그인에 workflow 권한 추가 후 `.github/workflows/`로 옮기면 켜져요).
