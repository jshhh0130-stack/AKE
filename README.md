# 에이크 · AKE

**당신이 채우는 순간, CAKE가 됩니다.**
손님과 케이크 가게 사장님이 한 앱에서 찾기 → 주문 → 대화 → 확정까지 끝내는 커스텀·레터링 케이크 앱이에요.

### 앱 바로 열기 → **https://jshhh0130-stack.github.io/AKE/**

- **아이폰**: 사파리로 위 주소 열기 → 공유 버튼(□↑) → **홈 화면에 추가**
- **안드로이드**: 크롬으로 열기 → **홈 화면에 설치** 버튼(또는 ⋮ 메뉴 → 앱 설치)
- **컴퓨터**: 가운데 핸드폰 화면 + 옆에 **QR 코드**와 **발표 시연 순서**가 보여요.

> 저장소 이름을 dear-cake → AKE 로 바꿨어요(2026-11-20). 예전 앱 주소(/dear-cake/)로 나눠 준 링크·QR은 새 주소로 다시 보내 주세요.

## 무엇을 할 수 있나요?

### 고객
1. **바로 지도** — 앱을 열 때마다 사장님용·고객용을 고르고, 고객용을 누르면 바로 지도가 열려요. 처음 한 번은 화면을 살짝 흐리게 하고 중요한 칸 5곳을 하나씩 짚어 줘요(건너뛰기 가능, 마이 › 사용법 다시 보기).
2. **지도 (캐치테이블처럼)** — 위에는 가게 이름 검색창, **AI로 케이크 가게 찾기** 막대, 조건 칩(동네 · 앱 주문 · 당일 픽업 · 종류), 오른쪽에는 **내 위치 · 위치 공유** 버튼이 있어요.
   - **AI로 케이크 가게 찾기**: 말로(“영통 4만원대 캐릭터”) · 사진으로 · 종류·예산·지역 조건으로 찾아요
   - **AI 실사 사진**: 넣은 사진(또는 앱 시안)을 AI가 실사 케이크 사진으로 바꿔요. “체리 많이”처럼 더 원하는 것도 적어요
   - **그림판**: AI 사진·시안·내 사진 위에 펜 · 크림 짜기 · 지우개 · 글자(케이크 글씨체)로 직접 고쳐요. 고친 사진으로 가게를 찾거나, 주문서 참고 사진으로 사장님께 보내요
   - 핀에 **1호 가격**이 보여요 (분홍 = 앱 주문, 흰색 = 가격 공개, 작은 회색 = 확인 필요)
   - 핀을 누르면 아래에 **가게 카드**가 뜨고, 옆으로 넘기면 다음 가게로 핀이 따라가요
   - 지도를 끌어 옮기면 **이 지역에서 다시 찾기**
3. **검색** — 가게 이름(띄어쓰기 무시 · 초성 · ‘제델’ 같은 줄임말), “영통 4만원대 캐릭터”처럼 말로 조건, 동네·역 위치, **사진으로 찾기**
4. **관심 (핀터레스트처럼)** — 케이크 사진을 2줄 엇갈린 격자로 둘러보고, 하트로 모아요.
   - 검색(곰돌이 · 하트 · 어버이날 · 핑크…), 관련 검색어, **내 사진과 비슷한 케이크**
   - 사진을 누르면 비슷한 케이크 + **이 케이크 만드는 가까운 가게** → 가게를 고르면 주문서에 그 디자인이 미리 채워져요
   - **찜한 가게**도 같은 탭에 있어요
5. **위치 공유** — 가게 위치(주소 + 카카오맵·구글 지도 링크), 가게 페이지, 내 위치, 지금 보는 곳을 카톡·문자로 보내요
6. **가게 상세** — 큰 사진(또는 스타일 그림), 1호 기본 가격, 주문 마감·픽업·휴무, 가격표, 주문 전 안내, 가게에 물어보기, 위치·길찾기
7. **한 페이지 주문서** — 고를 때마다 케이크 시안과 가격이 바뀌고, 문구를 한 글자씩 확인해요
8. **주문 대화방 · 알림** — 승인 / 수정 제안, 제작 전 시안 확인·수정 요청, 주문 고치기, 사진·메시지, 알림 켜고 끄기

### 사장님
1. **3분 등록** — “우리 가게 찾기”로 공개 정보를 미리 채우고 4단계로 끝
2. **주문 링크·QR** — 인스타 프로필·계산대에 걸어 두면 손님 폰의 주문이 사장님 폰에 **실시간으로** 도착
3. **오늘** — ① 확인할 주문 ② 새 소식 ③ 오늘 픽업
4. **주문 대화방** — 승인 / 수정 제안, 시안 사진 보내기, 입금 확인, 제작 → 픽업 (가격표 안의 주문은 자동 확정)
5. **매출 · 월별 장부 · 근무기록** — 그래프, 정산 예정, 달력 장부, 엑셀 저장, 시급·월 급여 계산

## 디자인
- 흰 바탕이 기본, 부분마다 **크림 베이지**와 **파스텔 핑크**(로고 색). 주 버튼은 딸기 로즈, 글자는 코코아 색.
- 그라데이션·이모지 없이 단색과 선 아이콘만. 카드 모서리 16 · 버튼 14 · 칩은 둥글게.
- 로고: 팀이 만든 **초 + AKE** 로고(`../AKE_로고_초앞_투명.png`)로 아이콘·파비콘·공유 이미지를 만들어요 → `node tools/make-icons.mjs`

## AI 실사 사진은 어떻게 만들어지나요
키가 없어도 무료로 동작해요. 아래 순서로 넘어가요.
1. **구글 제미나이**: 마이 › 지도 · AI 연결에 키를 넣으면 가장 정확해요(유료, 1장 약 50~100원).
2. **무료 AI (FLUX.1 Kontext · schnell)**: 허깅페이스 공개 데모. 인터넷 주소마다 하루 몇 번 무료예요. 허깅페이스 무료 토큰을 넣으면 더 많이 써요.
3. **무료 대기열 (AI Horde)**: 위 둘이 안 되면 무료 공개 생성망에 줄을 세워요(10~20분). 앱을 닫았다 열어도 이어서 기다리고, 다 되면 알림이 와요.
- AI는 한글 글씨를 잘 못 그려서, 사진의 문구는 지우고 **그림판에서 케이크 글씨체로 얹어요**.
- 만든 사진은 **관심 › 내가 만든 사진**에 모여요(이 기기에만, 최근 8장). 실제 가게 작품이 아니라 ‘예시’로 표시해요.

## 구글 지도 연결
앱 **마이 › 지도 · AI 연결**에 Google Maps API 키를 넣으면 지도가 구글 지도로 바뀌고, 가게의 **실제 사진 · 별점 · 영업시간**을 구글에서 받아 와요.
키가 없으면 무료 지도(OpenStreetMap, 색을 차분하게 눌러 씀)로 똑같이 동작해요. → [docs/구글지도-연결.md](docs/구글지도-연결.md)

## 주문·대화가 전달되는 방식
- 입점 가게로 보낸 주문과 대화는 **기기에서 암호화**(AES-GCM / ECDH)한 뒤 공개 중계 서비스(ntfy.sh)를 거쳐 상대 폰으로 가요. 중계 서버는 내용을 읽을 수 없고 12시간만 보관해요.
- 주문 기록은 각자 기기에 저장돼요. 정식 서비스로 가려면 → [docs/실서비스-전환.md](docs/실서비스-전환.md)

## 개발 메모
```bash
npm install
npm run dev                       # 개발 서버
node tools/deploy.mjs             # 빌드 → gh-pages 배포 + main 올리기
node tools/make-icons.mjs         # 로고 → 앱 아이콘·파비콘·공유 이미지
node tools/gallery/build.mjs      # 관심 탭 사진 줄이기 + 한글 문구 얹기 → public/gallery, src/data/gallery.json
node tools/walk.mjs               # 화면 자동 점검 (한 기기)
node tools/walk-live.mjs          # 폰 두 대 실시간 주문·대화 점검
node tools/walk-ai.mjs [--wait]   # AI 실사 사진 · 그림판 점검 (--wait: 무료 대기열 사진 완성까지)
node tools/look.mjs               # 디자인 확인용 스크린샷
```
- AI 실사 사진: `src/lib/imagegen.js`(엔진 순서), `src/components/AIStudio.jsx`(사진 창), `src/components/Sketch.jsx`(그림판)
- React 19 + Vite, 지도: Google Maps / Kakao / Leaflet(OpenStreetMap), 케이크 시안: 자체 SVG 엔진(`src/lib/cake.js`)
- 첫 화면 안내: `src/components/Coach.jsx`, 위치 공유: `src/components/Share.jsx`, 관심: `src/screens/customer/Interest.jsx`
- 저장 키(`dearcake:v2`)는 그대로예요. 바꾸면 이미 쓰던 사람의 주문·찜이 사라져요.
